# Frogie's Arcade — Static Edition

A responsive, single-page arcade hub.

## Files
- `index.html` — complete page markup, embedded CSS, and embedded JavaScript.
- `assets/frogiee-logo.svg` — Frogie's Arcade wordmark used by the page.

The page loads the logo from jsDelivr:

`https://cdn.jsdelivr.net/gh/atharvchoudhari123/FrogieeArcade-static@main/assets/frogiee-logo.svg`

Raw GitHub fallback:

`https://raw.githubusercontent.com/atharvchoudhari123/FrogieeArcade-static/main/assets/frogiee-logo.svg`

## Features
- Responsive arcade-style home screen.
- Links to the existing Math, Reading, Partners, Extras, Settings, and Privacy routes on the Frogie's Arcade domain.
- DuckDuckGo search.
- Local-only display name and region preferences.
- Mobile Game Sizer preference.
- Version/update dialog.

## Deploy
Enable GitHub Pages for the `main` branch and `/(root)`, or serve the repository root with any static host.

This is a static front-end. It does not bundle the site's original game files, server-side services, accounts, or proxy backend. Links to the existing site sections continue to use the Frogie's Arcade domain.
