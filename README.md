# Frogiee Arcade — Static Edition

A self-contained, responsive educational landing page.

## Files
- `index.html` — complete page markup, embedded CSS, and embedded JavaScript.
- `assets/frogiee-logo.svg` — original Frogiee logo.
- `assets/learning-hero.svg` — original learning illustration.

The HTML loads its SVG assets from jsDelivr:

`https://cdn.jsdelivr.net/gh/atharvchoudhari123/FrogieeArcade-static@main/assets/...`

Raw GitHub equivalents:

`https://raw.githubusercontent.com/atharvchoudhari123/FrogieeArcade-static/main/assets/...`

## Deploy
Enable GitHub Pages for the `main` branch and `/(root)`, or serve the repository root with any static host.

This is an original static implementation, not a copy of third-party proprietary source code or course content. Interactive subject cards show sample activity ideas; there is no account system or backend.
